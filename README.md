An entry for the [Alien Field Notes: The Two Day Earth Review](https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000) bounty on [make.fun](https://make.fun).

`main.py` (Python, stdlib only, deterministic) writes one line to
`entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default
`/output`): a review of planet Earth left by an alien tourist after
two days of field observation — deadpan, confident, and wrong about
why humans photograph their food. After writing, it reads the file
back and verifies it against the competition gate: UTF-8 text of
1–200 characters, not only white space, a single line.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
